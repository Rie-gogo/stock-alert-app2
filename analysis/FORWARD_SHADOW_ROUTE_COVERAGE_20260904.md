## 推奨する作成順

最初は、名目TPがSLの2倍未満であり、勝率が高くても1回の損切りで利益を失いやすい経路を優先します。そのため、**9984 → 6976候補B → 6526 → 3436 → 5803安値反転LONG → 6976後場SHORT → 6981安値反転LONG**の順が妥当です。

その後は、TP/SLは適合しているものの改善候補が0件の経路を進めます。順序は、既に本番対シミュレーション乖離の影響を調査している5803を先にし、**5803の2つのSHORT → 6857の2経路 → 6146の2経路 → 6981寄り付きSHORT → 8035の予備LONG/SHORT**とします。

285Aの残り4経路にはATR案が1つずつあるため、新規0件の経路を一巡した後に第2案を作るのが安全です。改善案は1案ごとに別 `strategyVersion`、別状態、別取引へ固定し、途中で条件を変更しません。
