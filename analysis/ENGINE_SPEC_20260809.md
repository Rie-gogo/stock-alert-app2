## 1. 資金管理

### 1.1 元金・証拠金

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 証拠金（元金） | **300万円** | MARGIN_CAPITAL |
| 信用倍率 | **3.3倍** | MARGIN_MULTIPLIER |
| 最大使用率 | **90%** | MARGIN_USAGE_LIMIT |
| **最大投資可能額** | **891万円** | 300万 × 3.3 × 0.9 |
| 1銘柄あたり投資額 | **300万円** | INITIAL_CAPITAL_PER_STOCK |

### 1.2 ロット計算

```
株数 = floor(300万円 × 0.9 / 株価 / 100) × 100
（100株単位に切り捨て）
```

### 1.3 日次損失上限（orderBridge: 自動売買時）

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| **日次損失上限** | **-100,000円** | この金額に達したら当日の新規エントリー全面停止 |
| 緊急停止 | 手動 | ダッシュボードの緊急停止ボタンで即時停止 |
| ドライランモード | デフォルトON | 実注文を出さずにシミュレーションのみ |

※ 日次損失上限はorderBridge.ts（自動売買ブリッジ）に実装。realtimeSimEngine.ts（シミュレーション）には未適用。

## 8. 大台確認シグナルの詳細フロー

### 8.1 SHORT（大台割れ）— 有効

```
1. 大台割れ検出（キリ番を下抜け）
2. 確認バーステートマシン登録
3. 4本連続で大台以下を維持（ROUND_LEVEL_CONFIRM_BARS = 4）
4. 押し目待ちステートマシンに移行
5. 押し目確認（一度反発→再下落）or タイムアウト（5本）
6. 板読みスコアチェック（≥1）
7. buy_pressure時はSHORTブロック
8. SHORTエントリー
```

### 8.2 LONG（大台超え）— 停止

```
※ 2026-08-09より全面停止
理由: 30日間で21件中3勝18敗（勝率14.3%）、-206,025円
構造的にエントリーが遅く、上昇日でも勝てない
```

### 8.3 逆張りSHORT（大台超え + buy_pressure）— 有効

```
1. 大台超え4本確認完了
2. 押し目待ちタイムアウト or 押し目確認
3. 板がbuy_pressure → LONGではなくSHORTに反転
4. SHORTエントリー（過熱からの反落を狙う）
理由: 30日間で10件中7勝（勝率70%）、+158,356円
```

## 9. isBullish判定の詳細

```
方式: MA20の1分あたり傾き（動的判定）

計算:
  MA20_current = 直近20本の終値平均
  MA20_prev = 1本前時点の直近20本の終値平均
  slope = (MA20_current - MA20_prev) / MA20_prev * 100 (%)

判定:
  slope > -0.03% → isBullish = true → SHORT禁止
  slope ≤ -0.03% → isBullish = false → SHORT許可

フォールバック（バッファ21本未満）:
  現在値 > 始値 × (1 + 0.2%) → isBullish = true
```

## 10. 板読みスコア計算

```
スコア = 0（初期値）

加点条件:
  +1: 板シグナルがエントリー方向と一致
      （LONG時: buy_pressure、SHORT時: sell_pressure）
  +1: 信頼度が"strong"

減点条件:
  -1: 板シグナルがエントリー方向と逆
      （LONG時: sell_pressure、SHORT時: buy_pressure）

判定: スコア ≥ 1 でエントリー許可
```
