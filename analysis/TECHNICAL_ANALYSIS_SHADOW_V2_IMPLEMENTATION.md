# テクニカル分析シャドー v2 実装・差分表

## 目的

ユーザー提示の「デイトレ用テクニカル分析機能 仕様案」を、既存の10銘柄テクニカルAへ統合する。通常取引、OrderBridge、Executor、formal Gate、自動採用には接続しない。

## 旧版との差分

| 項目 | 旧版 | v2 |
|---|---|---|
| 時間軸 | D-1日足・60分足と当日1分足の簡易判定 | D-1日足、当日確定5分足、当日確定1分足を分離保存・判定 |
| 移動平均 | 日足5/20/25/50、当日簡易VWAP | 1分・5分SMA5/21/50、EMA12/26、日足SMA5/21/50 |
| MACD | なし | 12/26/9、シグナル、ヒストグラム、ゼロライン材料 |
| ATR・出来高 | ATR、直近10本出来高 | ATR14、出来高20本平均・倍率 |
| オシレーター | なし | RSI14、ストキャス14/3/3、RCI 9/26/52 |
| ボリンジャー | D-1日足だけ | D-1日足に加えて1分・5分20本±2σ |
| 相場状態 | 日足中心のup/down/range | 1分・5分・日足を別判定し、不一致時はmixed/hold |
| 入口 | 前日高安ブレイク、前日高安反転 | 押し目、戻り、SMA21転換、支持抵抗ブレイクの維持/再確認、レンジ反転 |
| MACD単独売買 | なし | 候補表示のみ。単独では発火不可 |
| パターン | なし | ダブルトップ/ボトム、三角、ウェッジ、フラッグ、ボックスを候補表示 |
| 支持抵抗 | 前日高安、BB、丸い価格 | ピボット、前日高安、簡易出来高価格帯を統合 |
| 出来高価格帯 | なし | typical-price binによる近似。高/低出来高帯を表示 |
| 損切り | 前日高安付近の固定buffer | 直近スイング、支持抵抗、ATRの複合候補 |
| 利確 | 最寄りD-1水準、1.2R未満拒否 | 最寄り技術水準を採用。固定1.2R拒否なし、2Rは反実仮想併記 |
| 利益保護 | なし | 1R到達後、次足以降のstopを建値へ移動 |
| 反対条件決済 | なし | 反対確認シグナル、SMA21割れ＋MACD確認を選択可能 |
| 表示根拠 | routeと価格中心 | 成立条件、未成立条件、参考価格、根拠、条件充足率を保存 |

リアルタイム画面には10銘柄の最新 `signal_quality` stateだけを60秒間隔で読む折り畳み表示を追加した。raw足の再集計やstate更新は行わず、受信・判定workerとは分離している。

## 発火と表示の区別

以下はシャドー取引へ進める。

- トレンド中の押し目買い／戻り売り
- SMA21転換確認
- 支持線・抵抗線ブレイク後の維持または再確認
- レンジ支持抵抗での反転確認

以下は誤検出防止のため表示・検証専用で、単独発火させない。

- MACD交差だけの候補
- ダブルトップ/ボトム、三角、ウェッジ、フラッグ、ボックス
- RSI、ストキャス、RCIの過熱圏だけの候補
- 板情報だけの候補

## 因果性と実行条件

- 指標計算は、その時点までに確定した1分足だけを使う。
- 5分足は5本の確定1分足が揃った時だけ完成扱いにする。
- D-1日足は閉場後snapshotを翌日固定し、当日損益で書き換えない。
- シグナル足では入らず、次の同銘柄source eventの100株depth VWAPを使う。
- 板時刻はclock-safeで5秒以内、時刻逆転なし、0.15%以内の不利約定を要求する。
- pattern/MACD-onlyは表示専用。
- 同一足でSLとTPが成立する場合はSL優先。
- 15:20以降はデイトレード決済する。

## 信頼度の意味

`confidenceCompleteness` は成立条件数 ÷ 全条件数であり、予測勝率ではない。実績勝率として表示・使用してはいけない。

## パラメータ管理

期間・閾値は `DEFAULT_TECHNICAL_ANALYSIS_CONFIG` に集約した。前向き評価中に画面から同じstrategyVersionを書き換えることは禁止する。設定を変更する場合は、新しい設定hash・strategyVersion・学習打切日・評価開始日を作り、旧版と並行比較する。

## データ上の制約

- 出来高価格帯は約定履歴の価格別出来高ではなく、1分足typical priceへ出来高を配賦した近似である。
- 板は入口・出口の実行可能価格確認に使い、単独の方向判断には使わない。
- 手数料・信用金利は証券会社設定が確定するまで0円。既存の0.10%不利決済損益は別列で保存する。
- 市場制度、値幅制限、即金規制はテクニカル判定と分離する。

## 安全境界

- 通常 `rt_trades` へ書かない。
- OrderBridge、Windows Executor、実注文instructionへ接続しない。
- formal Gateを自動承認しない。
- 自動採用・自動停止・自動置換をしない。
- 現行ロジック、既存個別シャドー、証拠金配分を変更しない。

## 検証段階

1. 純粋指標・相場状態・因果性の単体試験。
2. 保存済み1分足による再生。銘柄・時間帯・シグナル種別別に集計。
3. 次イベント板、0.10%不利決済、欠損日除外を含む再生。
4. 10銘柄で前向きシャドー。4週間かつ10件以上を満たして人が審査。
5. 合格後も自動採用せず、別checkpointで判断する。
