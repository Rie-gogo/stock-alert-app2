# 市場環境対応型・選択器専用シャドー v1

## 目的

銘柄別の現行ロジックと改善シャドーを止めず、前日までに固定した経路別候補を、当日の日経平均系の方向で再評価する。これは監視専用であり、通常取引、既存シャドー、証拠金、OrderBridge、Executor、実注文へ接続しない。

## 段階

### 開場前 ①〜③

平日08:30 JSTの別タスクで、以下を調査し、人向け報告と機械読取用JSONを作成する。

- NYダウの前営業日比
- CME日経平均先物と前日OSE日中立会終値の差
- USD/JPYの前日15:30 JST比

JSONは数値、観測時刻、HTTPS出典、品質状態を必須とする。CMEはOSE日中立会終値と直接比較できる円建て同等契約だけをverifiedとして扱い、ドル建てしか確認できない場合は換算せずdegradedとする。欠損値を推測で補完しない。

アプリには保護された`pushPremarketMarketContext`入口と専用の追記保存表を設ける。同一`sourceSnapshotId`の内容が異なる再送は拒否し、文章そのものではなく構造化値だけを保存する。現段階では、08:30タスクからこの入口へ自動送信する外部データ連携は未接続である。

v1の方向判定は、結果を見て当日変更しない固定値とする。

- NYダウ前日比: ±0.30%で1票、±1.00%で2票
- CME円建て価格のOSE日中終値比: ±0.35%で1票、±0.90%で2票
- USD/JPY変化率: ±0.20%で1票、±0.60%で2票
- verifiedが2項目未満なら判定不能
- 合計±2票で上昇/下落、±4票で強い上昇/強い下落
- snapshotは対象取引日の9:00 JSTより前に凍結し、凍結後に観測された値は先読みとして無効

### 場中 ④

Windows relayは、通常10銘柄と別の市場環境参照として日経225mini直近限月を1銘柄だけ登録する。通常の`pushCandle`ではなく専用の`pushMarketContext`へ送り、専用テーブルへ追記保存する。

判定時刻は確定した1分足に対して固定する。

| 利用する確定足 | 判断時刻 |
|---|---|
| 09:04 | 09:05 |
| 09:14 | 09:15 |
| 09:59 | 10:00 |
| 12:34 | 12:35 |
| 13:29 | 13:30 |

分類は、強い上昇、上昇、方向不一致、下落、強い下落、ギャップ安から回復、ギャップ高から失速、判定不能とする。v1の閾値はコードで固定し、当日の結果を見て変更しない。

## 選択対象

前日閉場後に凍結済みの`route_granular_next_day_selector` snapshotだけを使う。選択可能で期待損益が正の経路のうち、①〜③と④を統合した許可方向に合うものを銘柄ごとに1件記録する。選ばれても取引や既存シャドー状態は変更しない。

統合規則も固定する。

- 開場前と場中が一致: 一致方向を採用
- 09:05/09:15に方向が衝突: 見送り
- 10:00以降も場中方向が継続: 場中方向を優先
- ギャップ安から回復/ギャップ高から失速: 場中の明示的反転を優先
- 開場前が高信頼で場中が方向不一致: 開場前方向を低信頼として記録

## 遅延防止

- 市場環境は通常銘柄とは別スレッド、別endpoint、別テーブルで扱う。
- 通常の`TARGET_STOCKS`、`realtimeSimEngine`、`sourceEventIngestion`、forward-shadow dispatcherを変更しない。
- UIの読取は最大1分間隔で、専用保存値だけを取得する。
- 同一分の再送は分類時に1本へ正規化する。

## 品質・受入条件

- `observedAt <= relaySentAt <= cloudReceivedAt`を満たさないeventは無効。
- 観測からrelay送信、またはrelay送信からcloud受信が120秒を超えたeventはdegradedとし、選択判断へ使用しない。
- REST補完は取得時点の単一価格であり1分OHLCではないため、保存・欠損診断だけに使いdegradedとして選択判断へ使用しない。
- 09:00〜15:30のverifiedな足だけを場中分類に使う。
- 同じ分の再送では同じsourceEventIdを再利用する。
- 翌営業日は、通常10銘柄の1分間隔・欠損・queue遅延が従来どおりであることを、市場環境受信とは分離して確認する。

## 未完了

- 開場前①〜③の構造化JSONを、認証済みのデータ提供経路からアプリへ自動送信する処理
- 市場環境で選んだ経路の閉場後損益と、固定運用との差の自動評価
- 未見期間を蓄積した後の人による採否判断

これらが完了するまで、①〜④を統合した最終選択器とは扱わない。
