# 9984 前場10本高値更新LONG：改善案A/B

作成日: **2026-09-05 JST**  
作成者: **Manus AI**  
目的: 現行DRY_RUNを変更せず、原理の異なる2つの前向きシャドー候補を固定するための提案

## 結論

現行経路は、09:40〜10:30の陽線で直前10本高値を終値更新し、MA8二本傾きが0.02%以上、出来高が直前20本平均の1.2倍以上なら、確定足終値でLONGします。出口はSL 0.8%・TP 0.3%・最大45分であり、シグナル反転と板読み早期利確は使いません。[1]

この経路の主な問題は、入口の勝率ではなく、**TP 0.3%に対してSL 0.8%で、1敗を取り戻すために約2.67勝が必要**なことです。保存KABU 44日・14,353足では25件23勝2敗、100株損益+29,675.8円でしたが、2026-08-31〜09-04の本番DRY_RUN 5件は4勝1敗で、100株換算では+1,348.6円に留まりました。合計30件では27勝3敗・勝率90.0%・+31,024.4円/100株です。[2]

提案する2案は、同じ数値の微調整ではありません。**A案は「実行できる価格でもブレイクが残っているか」を確認する入口・約定品質案**、**B案は入口を一切変えず、2R出口と利益保護へ変更する損益構造案**です。

| 項目 | 改善案A | 改善案B |
|---|---|---|
| 変更する主因 | ダマシ・理論終値と実行可能価格のずれ | TPよりSLが大きい損益構造 |
| 入口 | 次の同銘柄イベントで板depth確認 | 現行のまま即時候補化 |
| 出口 | SL 0.4% / TP 0.8% / 45分 | SL 0.5% / TP 1.0% / 利益保護 / 45分 |
| 名目TP/SL | 2.0倍 | 2.0倍 |
| 過去評価の扱い | raw depthが旧fixtureにないため正式成績なし | 粗い日次再生では25件19勝6敗・76.0% |
| 主なリスク | 取引数減少、板不足、通信遅延 | 現行より過去利益・PFが低下する可能性 |

## 改善案A：次イベント板depth・ブレイク継続確認

### 狙い

現行はブレイク足終値を入口価格にしますが、確定足を受信した時点でその終値へ必ず入れるわけではありません。そこで、次に同じ9984のイベントを受信した時点で、**売り板を100株分以上食ったask-side depth VWAP**を実行可能価格の近似として計算し、その価格でも元のブレイクが維持されている場合だけ仮想エントリーします。

### 固定仕様

| 項目 | A案仕様 |
|---|---|
| strategyVersion案 | `forward-shadow-9984-breakout-depth-confirm-v1` |
| 元シグナル | 現行9984前場10本高値更新LONGを完全維持 |
| pending開始 | 現行シグナル確定時。まだ取引しない |
| 確認時点 | 次の同一銘柄source eventだけ |
| 価格 | ask側を100株まで積み上げたdepth VWAP |
| ブレイク維持 | depth VWAPが元の直前10本高値より上 |
| 最大価格悪化 | depth VWAPがシグナル足終値より0.10%を超えて高ければ拒否 |
| 板数量 | ask合計が100株未満なら拒否 |
| 板鮮度 | relay内＋cloud内の同一時計区間合計が5秒以下。network transit未計測を明示 |
| 時刻因果 | board `observedAt` がA案の `decisionAt` 以下 |
| 出口 | SL 0.4% / TP 0.8% / 最大45分境界の確定足終値 |
| 拒否時 | 日次枠を消費せず、元の初動を再利用しない。後続の新規ブレイクを探索 |

この案ではBPRや特定日の値を入口へ足しません。過去の2敗は発火時特徴が大きく異なり、単純なATR、陽線実体、終値位置、同時点BPRの一条件では共通除外できなかったためです。保存板は16,042行中15,993行に存在しますが、旧44日fixtureにはraw depthが含まれないため、A案の正式な過去勝率は提示しません。

### 判定理由

> A案は「過去の負けに合う閾値」を探すのではなく、シミュレーションと本番の間にある**実行可能価格の差**を直接測る案です。

したがって、A案の価値は過去勝率ではなく、前向き期間での「現行シグナルのうち、板不足・レンジ戻り・0.10%超の価格悪化を何件止め、その後の損益がどう変わったか」で判断します。

## 改善案B：2R出口＋小幅利益保護

### 狙い

B案は入口を現行と完全に同じにし、損益構造だけを変更します。通常出口を**SL 0.5%・TP 1.0%**へ変更し、一度+0.20%まで上昇した取引が次の確定足以降に+0.05%へ戻った場合だけ、小さな利益を残して終了します。

### 固定仕様

| 項目 | B案仕様 |
|---|---|
| strategyVersion案 | `forward-shadow-9984-breakout-rr2-protect-v1` |
| 入口 | 現行と同じ確定足・同じ理論終値 |
| 通常SL / TP | 0.5% / 1.0% |
| 利益保護準備 | エントリー後に高値が+0.20%以上へ到達 |
| 判定開始 | 到達した確定足では決済せず、次の確定足から |
| 利益保護線 | +0.05%。次足以降の安値が到達したら決済 |
| 窓下げ | 保護線より当足始値が低ければ、より不利な当足始値を採用 |
| 同一足優先 | SL → 既に準備済みの利益保護 → TP → 新規準備 → 時間決済 |
| 最大保有 | 現行と同じ45分境界の確定足終値 |
| 反転・板早期利確 | 現行と同じく使用しない |

### 粗い過去確認

保存KABU 44日・現行と同じ25エントリーを固定した日次再生では、SL 0.5%・TP 1.0%・+0.20%到達後+0.05%保護は**25件19勝6敗・勝率76.0%・PF 2.78・+24,433.7円/100株**でした。保護準備を0.18%または0.22%にしても同じ成績、0.24%では18勝7敗・72.0%でした。このため0.20%一点だけへの依存は比較的小さい一方、現行の+29,675.8円/100株より過去損益は低下しています。[2]

この結果は候補成立の確認に過ぎません。後続再探索、同時点board、受信順portfolio、0.10%不利約定を完全に再現した正式なシミュレーションではないため、採用成績へ混ぜません。

## 不採用にする入口微調整

過去2敗の入口特徴は、2026-07-13がATR7率0.392%・ブレイク幅1.424ATR・始値比+2.170%、2026-08-21がATR7率0.164%・ブレイク幅0.574ATR・始値比+0.990%でした。両者のボラティリティとブレイク幅は共通していません。また、終値位置CLV 0.75以上、陽線実体比0.50以上、ブレイク幅0.10ATR以上の各条件は2敗を除外せず、勝ちだけを減らしました。

したがって、以下は改善案として採りません。

- ATRの単純な上限または下限
- 陽線実体や終値位置の単純な引き上げ
- 同時点BPRの単純な下限
- 特定時刻の除外

これらは今回の少数損失へ合わせた過学習になりやすく、A案の実行価格確認より因果関係が弱いためです。

## 前向き評価の固定条件

両案は現行9984と完全に分離し、通常`rt_trades`、OrderBridge、Executor、LIVE注文へ接続しません。`signal_quality`は全候補100株固定、`portfolio`は現行10銘柄・891万円共有として別集計します。

| Gate | 条件 |
|---|---|
| バージョン固定 | A/Bを別strategyVersion・別state・別judgment/tradeへ固定し、途中変更しない |
| 正式開始 | 実装・checkpoint・公開・初回実受信確認の**翌営業日**。今回の既存候補の開始日とは別に設定 |
| 経路parity | 9984現行経路の実時対固定版再生一致を採用判定前に必須化 |
| 2週間 | 継続または停止の中間判定だけ。採用不可 |
| 最終判定 | 4週間かつ10件以上。10件未満なら最大8週間 |
| 最低成績 | 勝率70%以上、PF 1.5以上、期待値+0.15R以上 |
| 実行耐性 | 0.10%不利後も損益プラス |
| 資金制約 | 100株全候補版と891万円portfolio版の双方で現行より悪化しない |
| 停止条件 | 5連敗または累計-6R |
| 採用方法 | 自動採用・自動置換なし。人が手動審査 |

## 推奨

**A案とB案を同時に前向きシャドーへ入れる**のが最も比較しやすい進め方です。A案は実行価格・ブレイク継続の乖離を測り、B案は高勝率でも損切り1回が重い問題を直接直します。A案は過去raw depth不足のため過去成績で優劣を付けず、B案も過去損益が現行より低いため、どちらも現時点では採用候補ではなく**未見評価候補**です。

## 前提・制約

分析基準日は2026-09-05 JSTです。利用データは保存KABU Station 1分足、同時点boardSnapshot、および現行DRY_RUN取引だけです。外部価格、未来足、実約定価格は使用していません。A案のdepth VWAPは実約定価格ではなく実行可能価格の近似です。
